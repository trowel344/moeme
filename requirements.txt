# moeme dependencies.
#
# The core library (src/moeme) and the unit tests need ONLY torch.
# Everything else is for the optional experiment scripts, which are marked below.
#
# On this machine torch/numpy/transformers were already present system-wide, so
# the recommended setup is a --system-site-packages venv (see `make venv`):
#   python3 -m venv --system-site-packages .venv && .venv/bin/pip install pytest

# --- core: required by src/moeme and tests/ ---
torch>=2.4

# --- optional: tools/bench_hardware.py (RAM/GPU bandwidth) ---
numpy>=1.26

# --- optional: experiments/pilot_sparsity.py (loading a real model) ---
# NOTE: Qwen3.5/Qwen3.8 use Gated DeltaNet, whose causal_conv1d kernel is
# CUDA-only in this environment. The pilot therefore requires a working CUDA
# device; it cannot run on CPU-only hosts.
#
# The floor is 5.6, not 4.51: the `qwen3_5` architecture exists only in the 5.x
# line, so a 4.x release installs cleanly and then cannot load the model at all.
# kaggle/upcycle_poc.ipynb pins ==5.6.2, the release every number here was
# measured on, and its install cell asserts the architecture is present.
transformers>=5.6
accelerate>=0.30
safetensors>=0.4

# --- optional: experiments/upcycle_poc.py (streaming a corpus) ---
# Without this the PoC falls back to a small built-in corpus, so it is only
# needed for a real run. It can also be pointed at a local file with --text-file.
datasets>=2.18

# --- dev ---
pytest>=8.0
